**Student Analyzer**



A beginner-friendly Python project that calculates student averages and assigns grades using object-oriented programming.



**Features**



\- Stores student names, ages, and marks.

\- Calculates average marks.

\- Assigns grades from A to F based on the average.

\- Handles students with no marks.

\- Displays results in a readable format.



**Technologies Used**



\-Python

\-Object-Oriented Programming (OOP)

\-Git and GitHub



**How to Run**



1\. Install Python 3.

2\. Clone or download this repository.

3\. Open a terminal in the project folder.

4\. Run: python student-analyzer.py
